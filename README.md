# GGPoker记录下载助手

一个帮助 GGPoker 用户下载游戏记录和历史手牌的 Chrome 扩展。

## 功能特点

- **权限控制**：仅付费/授权用户可用，需登录后才能使用主功能。
- **登录体验**：
  - 支持用户名、密码输入
  - 记住密码选项
  - 自动填充上次登录信息
  - 登录失败有友好提示
  - 支持中英文双语界面
- **用户信息展示**：
  - 登录后主界面顶部显示用户名和到期时间
  - 清晰的状态反馈
- **记录下载**：
  - 支持自定义日期范围（最长360天）
  - 支持日期间隔分批下载（1-3天）
  - 支持一键开始、暂停、恢复、停止
  - 智能分批处理，避免超时
  - 自动跳过无数据日期
- **状态反馈**：
  - 实时显示下载进度和状态
  - 支持多种状态提示（成功、警告、错误等）
  - 详细的日志记录
  - 人性化的错误提示
- **数据安全**：
  - 所有敏感信息仅存储于本地
  - 绝不上传服务器
  - 支持清除本地缓存
- **兼容性**：
  - 仅支持 Chrome 114+
  - 仅在 GGPoker 官方网站可用
  - 采用 Side Panel 现代界面
  - 支持响应式布局

## 系统要求

- Chrome 浏览器 114 或更高版本
- 仅支持 GGPoker 官方网站：
  - https://my.pokercraft.com/*
  - https://*.ggpoker.com/*
  - https://gateway.realtimegto.com/*

## 安装方法

1. 从 Chrome 网上应用店安装
   - 访问 Chrome 网上应用店
   - 搜索 "GGPoker记录下载助手"
   - 点击"添加到 Chrome"

2. 手动安装（开发版）
   - 下载本项目的 ZIP 文件并解压
   - 打开 Chrome 浏览器，进入扩展程序页面 (chrome://extensions/)
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择解压后的文件夹

## 使用说明

1. 在 GGPoker 网站上点击扩展图标，打开 Side Panel
2. 首次使用需要登录：
   - 输入用户名和密码
   - 可选择"记住密码"
   - 点击"登录"按钮
3. 登录成功后设置下载参数：
   - 选择开始日期和结束日期（最长360天）
   - 选择日期间隔（1-3天）
4. 点击"开始"按钮开始下载
5. 下载过程中可以：
   - 点击"暂停"按钮暂停下载
   - 点击"停止"按钮终止下载
   - 查看实时下载进度和状态
6. 下载完成后：
   - 记录会保存在浏览器的下载目录中

## 技术架构

- **前端界面**：
  - 使用原生 HTML/CSS/JavaScript
  - 采用 Side Panel API 实现现代界面
  - 响应式设计，适配不同屏幕尺寸
- **后台服务**：
  - 使用 Chrome Extension Manifest V3
  - Background Service Worker 处理核心逻辑
  - Content Script 实现页面交互
- **数据存储**：
  - Chrome Storage API 存储配置和状态
  - 本地文件系统保存下载记录
- **安全机制**：
  - 基于 Token 的身份验证
  - 本地加密存储敏感信息
  - 严格的域名白名单

## 注意事项

- 需要 Chrome 114 或更高版本才能使用 Side Panel 功能
- 仅支持 GGPoker 官方网站，其他网站无法使用
- 建议每次下载的日期范围不要太大，以免影响性能
- 下载过程中请保持网络连接稳定
- 如遇到异常，可以：
  1. 刷新页面后重试
  2. 检查网络连接
  3. 确认登录状态
  4. 查看错误提示

## 隐私说明

- 本扩展仅在 GGPoker 官方网站上运行
- 不会收集或上传任何个人信息
- 所有数据仅保存在本地浏览器中
- 支持随时清除本地缓存数据

## 常见问题

1. 为什么扩展图标点击后没有反应？
   - 请确认您正在访问 GGPoker 官方网站
   - 检查 Chrome 浏览器版本是否满足要求
   - 确认扩展是否已正确安装

2. 下载过程中断怎么办？
   - 可以重新设置日期范围继续下载
   - 已下载的记录不会重复下载
   - 系统会自动跳过已处理的日期

3. 如何查看已下载的记录？
   - 下载的记录会保存在浏览器的下载目录中
   - 可以使用RtGTO导入，形成分析结果

4. 登录失败怎么办？
   - 检查用户名和密码是否正确
   - 确认网络连接是否正常
   - 尝试清除浏览器缓存后重试
   - 联系客服获取支持
